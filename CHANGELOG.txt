===============================================================================
v1 — ORIGINAL RELEASE
===============================================================================
- Original public release of The Asteroid Space Game.
- Core asteroid-shooter gameplay.
- Player-controlled spaceship.
- Asteroid destruction.
- Basic scoring and progression.
- First version published on GitHub.

===============================================================================
v15 — MAJOR GAME UPDATE
===============================================================================
v15 is the second public release of The Asteroid Space Game.

This release combines all development and improvements created after v1,
including the internal work developed through versions v2–v14.

GAME WORLD
- Added a much larger scrolling space map.
- Added camera-follow movement.
- Added world boundaries.
- Improved asteroid spawning outside the current camera view.
- Added zoom controls:
  - On-screen + / -
  - Keyboard + / -
  - Mouse wheel
- Improved mobile HUD sizing.

PC & MOBILE CONTROLS
- Added support for PC, iOS, and Android browsers.
- PC controls include:
  - WASD / Arrow Keys — Fly
  - Space — Fire
  - R — Reload
  - M — Ship Systems
  - I — Game Info
  - O — Settings
  - ESC — Close menus
  - + / - — Zoom
  - Mouse wheel — Zoom
- Added touch controls for mobile devices.

ENGLISH GAME INTERFACE
- Converted the visible in-game interface to English.
- Menus, buttons, messages, upgrades, ranks, and information screens use English.

SAVE CODE SYSTEM
- Added personal 4–5 digit SAVE CODES.
- Added SAVE CODE generator.
- Added START / LOAD system.
- Added automatic saving.
- Progress is stored locally in the browser.
- Saved information includes credits, score, lives, asteroid kills, upgrades,
  Ship Titles, magazine state, ship color, zoom, ship state and extra hearts.
- Game Over deletes the active run.
- Save Codes work on the same browser/device where the save was created.

SPACE RANK SYSTEM
- Rookie — 0
- Space Cadet — 35
- Space Officer — 65
- Space Sergeant — 90
- Space Colonel — 115
- Space Lieutenant — 165
- Space Captain — 215
- Space Commander — 300
- Starship Commander — 400
- Space Marshal — 500
- Space Admiral — 600
- Starship Admiral — 700
- Galaxy Commander — 800
- Cosmic Commander — 900
- Space God — 1,000

SHIP TITLES
- King — 100 credits — Gold ship — x2 credits
- Master — 700 credits — Light-blue ship — x3 credits
- Legend — 1,500 credits — Legend design — x5 title bonus
- Full King + Master + Legend set activates x11 credits.

CREDIT REWARDS
- Destroying asteroids awards credits.
- Every 10 destroyed asteroids awards a base 15-credit bonus.
- Ship Title multipliers also affect the 10-asteroid bonus.

RED ELITE ASTEROIDS
- Every 5th spawned asteroid becomes a Red Elite Asteroid.
- Red Elite Asteroids have more health.
- Red Elite Asteroids award x2 normal asteroid credits.
- Elite rewards stack with Ship Title multipliers.

UPGRADES
- Weapon upgrades increase firing speed.
- Weapon level 2+ adds alternating side cannons.
- Magazine upgrades were added.
- Magazine upgrades also increase bullet damage.
- Engine upgrades increase thrust, maximum speed, and turning speed.
- Shield upgrades increase maximum shield and shield regeneration.
- Added manual reload and automatic empty-magazine reload.

SHIP COLORS
- Red — 25 credits
- Green — 25 credits
- Orange — 25 credits
- Purple — 25 credits
- Pink — 25 credits
- Reset to Normal — 30 credits
- Ship colors only affect appearance.
- Ship Title and Space Rank bonuses remain active.
- Selected color is stored with SAVE CODE.

EXTRA HEARTS
- Added purchasable extra hearts.
- Each heart costs 150 credits.
- One opportunity unlocks at Space Rank #5.
- One opportunity unlocks at Space Rank #10.
- No new heart purchases unlock after Rank #10.
- Maximum: 2 extra hearts per run.
- Heart purchases are stored with SAVE CODE.

AUDIO & SETTINGS
- Added space ambience.
- Added engine/thrust audio.
- Added rocket ignition.
- Added laser-shot sounds.
- Added credit sounds.
- Added purchase/upgrade sounds.
- Added dedicated SETTINGS menu.
- Added controls for:
  - ALL AUDIO
  - MUSIC
  - SPACE
  - ENGINE
  - SHOTS
  - CREDITS
  - UPGRADES

INFO MENU
- Added PC controls.
- Added Space Rank list.
- Added Ship Title information.
- Added upgrade descriptions.
- Added Red Elite Asteroid information.
- Added credit reward information.
- Added SAVE CODE information.

DEEP-SPACE VISUAL EFFECTS

- Improved the overall space atmosphere.
